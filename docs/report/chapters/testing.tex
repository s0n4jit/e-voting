\chapter{Test Plan and Test Report}
\label{chap:test}

\section{Strategy}

Testing combines three levels.

\begin{itemize}
  \item \textbf{Unit tests} of models, validators, password hashing and the vote service.
  \item \textbf{Integration tests} that call the real HTTP endpoints against an in-memory database: installation, registration, booth set-up, voting, results, audit.
  \item \textbf{Security tests} for authentication bypass, role escalation, injection, cross-site scripting, rate limiting, duplicate ballots and election isolation.
\end{itemize}

Selected behaviour was additionally checked manually in a browser against a PostgreSQL-backed Docker stack that is isolated from any production database.

\section{Defects found and fixed during testing and review}

\begin{itemize}
  \item A fixed two-step code accepted for every account, a fixed maintenance PIN and built-in booth tokens were removed.
  \item A database lock taken during migrations was never released and could freeze start-up; it is now taken on its own connection.
  \item Rate limits were counted separately by each server process; the container now runs a single process with threads.
  \item The default global rate limit would have throttled a whole campus behind one address.
  \item A stacking problem hid the backdrop of pop-ups behind the sidebar; a focus problem made forms lose focus after one character.
  \item Results were readable by officers before publication and during voting; they are now withheld by the server.
\end{itemize}

\section{Known limitations and untested areas}

\begin{itemize}
  \item No automated browser tests and no frame-rate measurements for animations; these were checked by eye.
  \item The booth lock-down scripts were not executed on physical hardware as part of the automated tests.
  \item Ballot rows and voter records both store the time of casting, so someone with direct database access could correlate them.
  \item A front-end routing dependency has a moderate advisory that needs a major upgrade.
  \item A load test with thousands of concurrent voters was not performed.
\end{itemize}

\section{Conclusion}

All 147 automated tests pass. The critical properties (one vote per voter, booth-only voting, hidden results, role enforcement) are covered by tests and were confirmed on PostgreSQL.
